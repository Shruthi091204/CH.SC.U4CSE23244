# Campus Notification System

A full-stack notification system for campus updates, results, and placements.

## Components
- **Stage 1**: Python script (`priority_inbox.py`) for ranking notifications using a Min-Heap.
- **Stage 2**: Next.js frontend (`notification_app_fe`) with a priority inbox and logging middleware.

## How to run
### Stage 1
`python priority_inbox.py`

### Stage 2
1. `cd notification_app_fe`
2. `npm install`
3. `npm run dev`
